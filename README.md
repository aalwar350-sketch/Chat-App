# Modern  Chat Interface 

A sleek, responsive, and interactive chat application interface designed with a focus on modern UI/UX principles. This project was developed as part of my web development journey to showcase advanced CSS techniques and interactive frontend logic.

##  Key Features
- **Modern UI Design:** Deep Midnight Blue theme with glassmorphism effects and neon accents.
- **Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, and Desktop) using CSS Flexbox.
- **Interactive Elements:** - Dynamic message bubbles with smooth animations.
  - Multi-colored call icons (Video & Audio) with hover scale effects.
  - Auto-scrolling chat history for better user experience.
- **Simulated AI Logic:** Implemented using JavaScript to mimic real-time bot responses.

##  Tech Stack
- **HTML5:** Semantic structure for better accessibility.
- **CSS3:** Custom properties (variables), gradients, and advanced hover effects.
- **JavaScript (ES6):** Dynamic DOM manipulation and event handling.
- **FontAwesome:** For high-quality, scalable vector icons.
